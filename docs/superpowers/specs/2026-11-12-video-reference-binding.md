# 视频参考输入修复

用户确认修复图片连接后被静默丢弃的问题。实际失败任务仅提交了 `<Picture 1>` 文本，没有 LoadImage 或 first_frame，生成了无关人物。

修复包括：
- 当前 H3 文生视频工作流增加可选 ref_image_01 LoadImage，连接到 H3 first_frame；纯文字时自动抹除未使用图片节点与连线，保留原模型、20步、队列、名称与ID。
- 前端在上传前根据实际工作流槽位及输出链路校验媒体类型和数量。没有槽位、槽位不可写、槽位与输出不连通、提供素材不可读时明确报错，禁止昂贵的无效生成。
- 首帧/尾帧图片和映射到首帧的单图参考按视频尺寸等比缩放并居中补边，不把人物非等比拉伸。补边可能显示在成片中；不声称保证后续全部帧人物一致。
- 不把首帧模式误称为多参考图模式；一张首帧入口最多接收一张图，多图/视频/音频没有对应槽位时报错。
- 服务器配置采用 revision CAS，先备份后更新四个模型/工作流副本。服务端固定worker与SQLite数据保留。

验证：缺槽位时零上传零提交；可接收图片时实际提交包含上传图片及到H3的连线；无参考图仍能文生；首尾帧工作流不丢图；图片缩放不改变比例；相关原有工作流测试与现场首帧视频生成。独立分支、审查、版本tag、远程构建部署和真实浏览器验收。
